============================================================
                COCOMOTION - Animation Packs
============================================================

Thank you for purchasing from Cocomotion Studio! This package
provides a professional-grade library of 330 high-quality
animations specifically optimized for Humanoid skeleton.

------------------------------------------------------------
1. REQUIREMENTS
------------------------------------------------------------
This package uses the modern Unity ecosystem:
* Unity 2021.3 LTS or higher (Recommended)
* Input System Package (com.unity.inputsystem)
* TextMesh Pro (for Demo UI)

------------------------------------------------------------
2. GETTING STARTED (DEMO SCENE)
------------------------------------------------------------
To preview the animations:
1. Open 'Assets/Cocomotion/NPC_Gestures/Scenes/DemoScene'.
2. Enter Play Mode.
3. Use RIGHT ARROW to play the next animation.
4. Use LEFT ARROW to play the previous animation.

------------------------------------------------------------
3. TECHNICAL SPECIFICATIONS
------------------------------------------------------------
All animations are pre-configured with industry-standard 
Root Motion settings to ensure perfect ground alignment:

* Rig Type: Humanoid
* Root Transform Rotation: Bake Into Pose (Based Upon: Original)
* Root Transform Position (Y): Bake Into Pose (Based Upon: Feet)
* Root Transform Position (XZ): Bake Into Pose (Based Upon: Original)
